# EconoLens
Econolens is an economic reporting A.I. system that ingests a large number of news articles from the world wide web on a daily basis into a knowledge base; it generates economic reports over requested periods of time and answers questions related to the U.S. economy. The system uses RAG (Retrieval augmented generation) architecture to store information in the news articles it downloads, and provides information to the main LLM (Large language model) based on the input prompt to generate an economic report or answer a question.

This project is underway and documentation is a work in progress
